# 🚲 Cyclistic Bike-Share Case Study

Welcome to my Capstone Project for the Google Data Analytics Professional Certificate! 

## 📊 Project Overview
The goal of this project is to analyze how annual members and casual riders use Cyclistic bikes differently. By understanding these usage patterns, the marketing team can design targeted strategies to convert casual riders into profitable annual members.

---

### 🛠 Tools & Technologies Used
- **Data Cleaning & Analysis:** Python (Pandas, NumPy) in Kaggle Notebooks
- **Data Visualization:** Tableau Public
- **Version Control:** GitHub

---

### 📈 Key Findings
1. **Ride Timing:** Annual members use bikes consistently throughout standard workdays (commuting pattern), while casual riders peak heavily on weekends.
2. **Trip Duration:** Casual riders take significantly longer trips on average compared to annual members.
3. **Bike Preferences:** Both user types engage with electric and classic bikes, providing distinct insights for membership promotions.

### 💡 Top Recommendations for Marketing
1. **Weekend Conversion Campaigns:** Target weekend casual riders with promotional passes at key leisure stations.
2. **Seasonal / Weekend Memberships:** Offer a tiered membership option tailored to long-duration casual riders.
